# Kumbh Crowdwatch Command

Build a polished, interactive web application named KumbhRakshak AI for Uttarakhand Police's Ardh Kumbh 2027 crowd safety project.

I am a beginner and need a demonstration-ready prototype in one week. Prioritize the visual experience and working interactions.

Design:

Professional dark navy command-centre theme with clear typography.

Left sidebar navigation.

Dashboard with camera count, active alerts, crowd-density warnings and camera status.

Four CCTV camera cards with video placeholders, fictional zone names and status indicators.

Crowd Analytics page with a crowd-density heatmap illustration, configurable density thresholds and sample people counts.

Weapon Detection page with a sample detection image, confidence display and evidence-review panel.

Person of Interest page using synthetic identities and sample candidate records only.

Interactive incident map with fictional camera markers and incident locations.

Incident History page with filters, timestamps, event categories and status controls.

Working interactions:

Add a button to simulate a crowd-density alert.

Clicking it should create an incident and update the dashboard's alert count.

Allow an operator to acknowledge, review and resolve an incident.

Clicking a camera should open its detail panel.

Allow filtering incidents by type, zone and status.

Make all navigation and buttons functional.

Use realistic fictional sample data and label simulated events clearly. Do not pretend that mock events are actual AI detections or live CCTV. Do not use real criminal identities or real police data.

First build the complete interface and working demo interactions. Verify that every page opens and every button works. Keep the application simple enough for a beginner to continue developing. Do not add unnecessary features or require paid APIs for the initial demonstration.
